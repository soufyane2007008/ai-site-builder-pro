### وصف الخطوات

| الخطوة | الفاعل | الإجراء | تفاصيل أمنية |
|--------|--------|---------|-------------|
| 1 | الأدمن | إدخال المفاتيح | حقول type="password" |
| 2 | الواجهة | الضغط على زر الحفظ | بدء عملية التشفير |
| 3 | الواجهة | عرض مودال | طلب Passphrase |
| 4 | الأدمن | إدخال Passphrase | لا تُخزن أبداً |
| 5 | Web Crypto | توليد Salt | 16 بايت عشوائية |
| 6 | Web Crypto | PBKDF2 | 100,000 تكرار |
| 7 | Web Crypto | توليد IV | 12 بايت عشوائية |
| 8 | Web Crypto | AES-GCM-256 | تشفير المفتاح |
| 9 | الواجهة | الحفظ في Firestore | ciphertext + iv + salt فقط |
| 10 | الواجهة | مسح الذاكرة | Passphrase = null |
| 11 | الواجهة | رسالة النجاح | Toast notification |
