### الخطوة 2: إدخال المفتاح

1. احصل على مفتاح API من الموفر:

   - [Google AI](https://makersuite.google.com/app/apikey)

### الخطوة 3: التشفير والحفظ

1. اضغط زر **"تشفير وحفظ المفاتيح"**

2. سيظهر مودال يطلب **كلمة المرور السرية**:
   ```
   ┌─────────────────────────────────────┐
   │  🔐 أدخل كلمة المرور السرية        │
   │  ┌─────────────────────────────────┐│

   │                                     │
   │  ⚠️ تذكر كلمة المرور — لا تُحفظ    │
   │                                     │
   │  [إلغاء]              [تأكيد]      │
   └─────────────────────────────────────┘
   ```

3. أدخل كلمة مرور قوية (8+ أحرف):
   - تحتوي حروف كبيرة وصغيرة
   - تحتوي أرقام
   - تحتوي رموز خاصة
   - **احفظها في مكان آمن!**

4. اضغط **تأكيد**

5. انتظر رسالة النجاح:
   ```
   ✓ تم تشفير وحفظ المفاتيح بنجاح
   ```

### الخطوة 4: التحقق من الحفظ

- يجب أن تظهر علامة ✓ خضراء بجانب كل موفر تم حفظ مفتاحه
- الحالة تتغير من "غير محفوظ" إلى "محفوظ"

## 🧪 اختبار إنشاء مشروع

### الخطوة 1: بدء مشروع جديد

1. من لوحة التحكم، اضغط **"مشروع جديد"**

2. اختر نوع الموقع:
   - صفحة هبوط (الأسرع للاختبار)
   - موقع شركة
   - معرض أعمال
   - متجر

### الخطوة 2: ملء البيانات

```
الخطوة 1: نوع الموقع
├── اختر: "صفحة هبوط"

الخطوة 2: الاسم واللغة
├── اسم المشروع: "موقع تجريبي"
├── اللغة: العربية

الخطوة 3: الألوان
├── اللون الأساسي: #3B82F6
├── اللون الثانوي: #F59E0B

الخطوة 4: المحتوى
├── وصف الموقع: "موقع تجريبي لاختبار المنصة"
```

### الخطوة 3: بدء التوليد

1. اضغط **"إنشاء الموقع"**

2. راقب شريط التقدم:
   ```
   ████████░░░░░░░░ 50%
   
   ✓ تحليل المتطلبات
   ✓ إنشاء الهيكل
   ⟳ توليد المحتوى...
   ○ إعداد SEO
   ○ إنشاء الملفات
   ```

3. انتظر حتى يكتمل (30-60 ثانية)

### الخطوة 4: معاينة النتيجة

1. عند الاكتمال، ستظهر:
   - زر **"معاينة"** → يفتح iframe
   - زر **"تحميل ZIP"** → يحمّل الملفات

2. تحقق من:
   - ظهور المحتوى بشكل صحيح
   - الألوان مطابقة للمختارة
   - الموقع متجاوب (جرب تصغير النافذة)

## 📦 تحميل ZIP والتحقق

### الخطوة 1: تحميل الملف

1. من صفحة المشروع، اضغط **"تحميل ZIP"**

2. انتظر إنشاء الملف (5-10 ثوانٍ)

3. سيبدأ التحميل تلقائياً:
   ```
   موقع-تجريبي.zip (50 KB)
   ```

### الخطوة 2: فك الضغط

1. فك ضغط الملف في مجلد

2. تحقق من الهيكل:
   ```
   موقع-تجريبي/
   ├── index.html
   ├── styles.css
   ├── main.js
   └── assets/
       └── (صور إن وجدت)
   ```

### الخطوة 3: اختبار محلي

1. افتح `index.html` في المتصفح

2. تحقق من:
   - تحميل الصفحة بدون أخطاء
   - ظهور المحتوى كاملاً
   - عمل التفاعلات (إن وجدت)
   - الروابط تعمل

### الخطوة 4: رفع للاستضافة (اختياري)

1. ارفع المجلد إلى:
   - Netlify Drop
   - Vercel
   - أي استضافة ثابتة

2. تحقق من عمل الموقع على الإنترنت

## 👥 إدارة المستخدمين

### عرض المستخدمين

1. من القائمة: **المستخدمون**

2. ستظهر قائمة تحتوي:
   ```
   | الاسم    | البريد              | الدور  | الحالة | الإجراءات |
   |----------|---------------------|--------|--------|-----------|
   | أحمد     | ahmad@example.com   | USER   | نشط   | [...]     |
   | سارة     | sara@example.com    | USER   | نشط   | [...]     |
   ```

### تغيير دور المستخدم

1. اضغط على زر الإجراءات (⋮)
2. اختر **"جعله أدمن"** أو **"إزالة الأدمن"**
3. أكد العملية

> ⚠️ لا يمكن تغيير دور SUPER_ADMIN

### إيقاف مستخدم

1. اضغط زر الإجراءات (⋮)
2. اختر **"إيقاف الحساب"**
3. أكد العملية

> المستخدم الموقوف لا يمكنه تسجيل الدخول
