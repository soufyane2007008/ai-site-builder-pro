## نظرة عامة

شاشة `Admin → AI Settings` مخصصة لإدارة مفاتيح موفري الذكاء الاصطناعي بطريقة آمنة. الهدف هو:
- إدخال المفاتيح دون عرضها
- تشفيرها قبل الحفظ
- عدم تخزين كلمة المرور

## العناصر المطلوبة

### 1. قسم التنبيه الأمني
- **النوع:** Alert Box
- **اللون:** أصفر/برتقالي (تحذيري)
- **المحتوى:** شرح موجز لآلية التشفير

### 2. حقول إدخال المفاتيح
لكل موفر (OpenAI, Gemini, Claude):

| العنصر | النوع | الوصف |
|--------|------|-------|
| أيقونة الحالة | Badge | 🟢 محفوظ / ⚪ غير محفوظ |
| اسم الموفر | Label | عنوان القسم |
| حقل المفتاح | Password Input | type="password" مع زر إظهار |
| نص توضيحي | Helper Text | تعليمات الاستخدام |

### 3. زر التشفير والحفظ
- **النوع:** Primary Button
- **الأيقونة:** 🔐
- **السلوك:** يفتح مودال كلمة المرور

### 4. قسم الاختبار
- **القائمة المنسدلة:** اختيار الموفر
- **زر الاختبار:** يفتح مودال كلمة المرور ثم يجري اختبار

## تذكيرات أمنية مهمة

1. **لا تُخزن Passphrase أبداً** — لا في LocalStorage ولا في الذاكرة طويلة المدى

2. **لا تعرض المفاتيح المفككة** — تظل مخفية حتى عند فك التشفير

3. **استخدم HTTPS فقط** — لضمان أمان النقل

4. **سجّل كل محاولة وصول** — في مجموعة logs

5. **حدد صلاحيات الوصول** — SUPER_ADMIN فقط يمكنه الوصول لهذه الشاشة
