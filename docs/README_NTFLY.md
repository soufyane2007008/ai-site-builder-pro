## 🔥 ربط Firebase (خطوات يدوية)

### المتطلبات الأساسية
1. حساب Firebase نشط
2. مشروع Firebase جديد
3. تفعيل الخدمات المطلوبة

### الخطوات

#### 1. إنشاء مشروع Firebase
1. اذهب إلى [Firebase Console](https://console.firebase.google.com)
2. أنشئ مشروعًا جديدًا باسم "ntfly-production"
3. فعّل Google Analytics (اختياري)

#### 2. تفعيل الخدمات
- **Authentication:** فعّل Email/Password, Google, GitHub
- **Firestore Database:** أنشئ قاعدة بيانات في وضع Production
- **Storage:** أنشئ bucket للملفات
- **Functions:** (اختياري) للعمليات الآمنة

#### 3. الحصول على مفاتيح التكوين
1. اذهب إلى Project Settings → General
2. أضف تطبيق ويب جديد
3. انسخ قيم التكوين

#### 4. إعداد المتغيرات البيئية
انسخ `.env.example` إلى `.env` واملأ القيم:

```
VITE_FIREBASE_API_KEY=           # مفتاح API العام للتطبيق
VITE_FIREBASE_AUTH_DOMAIN=       # نطاق المصادقة (projectId.firebaseapp.com)
VITE_FIREBASE_PROJECT_ID=        # معرف المشروع الفريد
VITE_FIREBASE_STORAGE_BUCKET=    # عنوان مخزن الملفات
VITE_FIREBASE_MESSAGING_SENDER_ID= # معرف مرسل الإشعارات
VITE_FIREBASE_APP_ID=            # معرف التطبيق
VITE_FIREBASE_MEASUREMENT_ID=    # معرف Analytics (اختياري)
```

> ⛔ **تحذير أمني:** لا تلصق المفاتيح أبدًا في:
> - ملفات عامة على GitHub
> - الكود المصدري المرئي
> - رسائل الدردشة أو المنتديات

## 🤖 الذكاء الاصطناعي الهجين

### نظرة عامة
يعمل نظام AI في Ntfly بطريقة هجينة:

```
┌─────────────────────────────────────────────────────────┐
│                    طلب توليد موقع                        │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │ فحص توفر مفاتيح AI   │
              └───────────────────────┘
                    │           │
            متوفرة  │           │  غير متوفرة
                    ▼           ▼
          ┌─────────────┐ ┌─────────────┐
          │ AI خارجي   │ │ AI محلي    │
          │ (Functions) │ │ (Templates) │
          └─────────────┘ └─────────────┘
                    │           │
                    └─────┬─────┘
                          ▼
              ┌───────────────────────┐
              │   توليد الملفات      │
              └───────────────────────┘
```

### المحرك المحلي (Fallback)
- يعمل بدون اتصال خارجي
- يستخدم قوالب محددة مسبقًا
- يولد محتوى عربي احترافي
- مناسب للوضع التجريبي

### المحرك الخارجي (عبر Functions)
- يتصل بـ OpenAI, Gemini, أو Claude
- يولد محتوى مخصص بناءً على الوصف
- يتطلب مفاتيح API صالحة
- **يجب أن يعمل من جانب الخادم فقط**

### طريقة الإدراج الآمنة (غير منفذة)
```
1. الأدمن يدخل مفتاح API في لوحة الإدارة
2. المتصفح يشفر المفتاح باستخدام AES-GCM + Passphrase
3. يُحفظ النص المشفر (ciphertext + iv) في Firestore
4. عند الحاجة للتوليد:
   - Firebase Function تطلب النص المشفر
   - الأدمن يدخل Passphrase لفك التشفير
   - Function تستدعي API الخارجي
   - لا يُكشف المفتاح أبدًا في الواجهة
```

## 🔒 ملاحظات أمنية

1. **المفاتيح:** لا تُخزن أبدًا بشكل صريح
2. **التشفير:** AES-GCM مع IV عشوائي
3. **Passphrase:** لا تُحفظ — تُستخدم في الذاكرة فقط
4. **API Calls:** من جانب الخادم فقط (Functions)
5. **RLS:** قواعد Firestore صارمة
6. **XSS:** تنظيف المحتوى المُولّد
