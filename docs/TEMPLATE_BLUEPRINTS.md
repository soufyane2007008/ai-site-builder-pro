## 1. قالب صفحة الهبوط (Landing)

### الهيكل المقترح

```
landing/
├── index.html          # الصفحة الرئيسية
├── styles.css          # الأنماط
├── main.js             # التفاعلات البسيطة
└── assets/
    ├── logo.svg        # الشعار (placeholder)
    └── hero-bg.jpg     # خلفية (placeholder)
```

### الأقسام المتوقعة

| القسم | المحتوى | ملاحظات |
|-------|---------|---------|
| Hero | عنوان رئيسي + وصف + CTA | صورة خلفية كبيرة |
| Features | 3-4 ميزات مع أيقونات | شبكة متجاوبة |
| About | نبذة مختصرة | صورة + نص |
| CTA | دعوة للإجراء | زر بارز |
| Footer | روابط + حقوق | معلومات التواصل |

### أمثلة محتوى

**بالعربية:**
```
العنوان: "ابنِ مستقبلك الرقمي معنا"
الوصف: "نقدم حلولاً مبتكرة تحوّل أفكارك إلى واقع رقمي متميز"
زر CTA: "ابدأ الآن"

الميزات:
- "سرعة فائقة" — "مواقع سريعة التحميل تضمن تجربة مستخدم مثالية"
- "تصميم متجاوب" — "يعمل بكفاءة على جميع الأجهزة والشاشات"
- "دعم مستمر" — "فريق متخصص جاهز لمساعدتك على مدار الساعة"
```

**بالإنجليزية:**
```
Title: "Build Your Digital Future With Us"
Description: "Innovative solutions that transform your ideas into reality"
CTA: "Get Started"

Features:
- "Lightning Fast" — "High-performance websites for optimal user experience"
- "Responsive Design" — "Works perfectly on all devices and screens"
- "24/7 Support" — "Expert team ready to help around the clock"
```

## 2. قالب موقع الشركة (Business)

### الهيكل المقترح

```
business/
├── index.html          # الصفحة الرئيسية
├── about.html          # من نحن
├── services.html       # خدماتنا
├── contact.html        # اتصل بنا
├── styles.css          # الأنماط الموحدة
├── main.js             # التفاعلات
└── assets/
    ├── logo.svg
    ├── team/           # صور الفريق
    └── services/       # صور الخدمات
```

### الأقسام المتوقعة

**الصفحة الرئيسية (index.html):**
- Header مع قائمة تنقل
- Hero Section
- نبذة مختصرة عن الشركة
- الخدمات المميزة (3-4)
- الإحصائيات (اختياري)
- آراء العملاء (اختياري)
- Footer

**صفحة من نحن (about.html):**
- قصة الشركة
- الرؤية والرسالة
- القيم
- الفريق (صور + أسماء + مناصب)

**صفحة الخدمات (services.html):**
- قائمة الخدمات مفصلة
- أيقونات/صور لكل خدمة
- CTA لكل خدمة

**صفحة اتصل بنا (contact.html):**
- نموذج تواصل
- معلومات الاتصال
- خريطة (placeholder)

### أمثلة محتوى

**بالعربية:**
```
الشركة: "شركة {الاسم} للحلول التقنية"
الشعار: "نبني المستقبل معاً"

الخدمات:
1. "تطوير المواقع" — "نصمم مواقع احترافية تعكس هوية علامتك التجارية"
2. "تطبيقات الجوال" — "تطبيقات ذكية تصل لعملائك أينما كانوا"
3. "التسويق الرقمي" — "استراتيجيات فعالة لزيادة وصولك"
4. "الاستشارات" — "خبراء متخصصون لتوجيه مشروعك نحو النجاح"

الإحصائيات:
- "500+" — "مشروع منجز"
- "50+" — "عميل سعيد"
- "10+" — "سنوات خبرة"
```

```
store/
├── index.html          # الصفحة الرئيسية
├── products.html       # جميع المنتجات

├── styles.css
├── main.js             # السلة + التفاعلات
├── cart.js             # منطق السلة
└── assets/
    ├── logo.svg
    └── products/
        ├── product-1.jpg
        └── ...
```

### الأقسام المتوقعة

**الصفحة الرئيسية:**
- Header مع سلة + بحث
- Hero/بانر ترويجي
- منتجات مميزة
- فئات المنتجات
- عروض خاصة
- Footer

**صفحة المنتجات:**
- فلترة حسب الفئة
- ترتيب (سعر، الأحدث)
- شبكة منتجات
- Pagination

**صفحة المنتج:**
- صور متعددة
- العنوان والسعر
- الوصف
- زر الإضافة للسلة
- منتجات مشابهة

**السلة:**
- قائمة المنتجات
- تعديل الكمية
- المجموع
- زر إتمام الطلب
