## خدمات Firebase المقترحة

### Firebase Authentication
- **الغرض:** إدارة تسجيل الدخول والمستخدمين
- **الموفرون:** Email/Password, Google, GitHub
- **الأدوار:** SUPER_ADMIN, ADMIN, USER, GUEST

### Cloud Firestore
- **الغرض:** تخزين البيانات المنظمة
- **المجموعات:** users, projects, ai_keys, logs, settings, feedback
- **القواعد:** RLS صارمة لحماية البيانات

### Cloud Storage
- **الغرض:** تخزين ملفات المشاريع المُنشأة
- **الهيكل:** `/projects/{userId}/{projectId}/`
- **الأنواع:** HTML, CSS, JS, صور, ZIP

### Cloud Functions (اختياري)
- **الغرض:** عمليات الخادم الآمنة
- **الدوال المقترحة:**
  - `generateWithAI` - استدعاء موفري AI
  - `createProjectZip` - إنشاء ملف مضغوط
  - `cleanupOldProjects` - تنظيف المشاريع القديمة

## ملاحظات أمنية معمارية

1. **فصل المسؤوليات:**
   - الواجهة: عرض فقط، لا منطق أمني
   - Functions: العمليات الحساسة
   - Firestore Rules: التحكم في الوصول

2. **حماية المفاتيح:**
   - التشفير في المتصفح قبل الإرسال
   - فك التشفير في Functions فقط
   - لا تخزين Passphrase

3. **التحقق المزدوج:**
   - Client-side للتجربة السريعة
   - Server-side للأمان الفعلي
